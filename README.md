# 美容室GRACE 予約サイト（リアルタイム予約）

富谷市成田の完全個室サロン「美容室GRACE」の予約サイトです。

- お客様：空き状況（○△×）を見て、その場で予約が確定
- お店：予約は **Googleスプレッドシート** に自動で記録＋**メールでお知らせ**
- 同じ時間に2人が同時に予約しても、先に届いた1件だけが入ります（ダブルブッキング防止）
- 前のお客様との間に準備時間（初期設定15分）を自動で空けます
- 費用：無料（GitHub Pages ＋ Googleスプレッドシート）

```
grace-site/
├─ index.html            … 予約サイト本体（GitHub Pagesで公開）
└─ apps-script/Code.gs   … 予約台帳（スプレッドシート）とつなぐプログラム
```

---

## ① 予約台帳をつくる（10分）

1. Googleドライブで **新しいスプレッドシート** を作成（名前は「GRACE 予約台帳」など）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初から入っている文字を全部消して、`apps-script/Code.gs` の中身をまるごと貼り付け → 💾保存
4. 上の関数選択で **`setup`** を選んで ▶実行
   - 「承認が必要です」→ 自分のGoogleアカウントを選ぶ →「詳細」→「（安全ではないページ）に移動」→ 許可
   - スプレッドシートに「予約」シートができればOK
5. 右上 **デプロイ → 新しいデプロイ** → 種類の歯車から **ウェブアプリ** を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」→ 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）をコピー

> 営業時間・定休日・準備時間は `Code.gs` の一番上の `SETTINGS` で変えられます。
> **Code.gs を書き換えたら**「デプロイ → デプロイを管理 → ✏️編集 → バージョン：新バージョン → デプロイ」で反映されます（URLは変わりません）。

## ② サイトとつなぐ

`index.html` の `const CONFIG = {` の中を書き換えます。

| 項目 | 内容 |
|---|---|
| `apiUrl` | ①でコピーしたウェブアプリのURL（**ここを入れるとデモ表示が消えて本番になります**） |
| `menu` | メニュー名・価格・所要時間（**今は仮の価格です**）。所要時間で予約枠の長さが決まります |
| `holidayText` / `parking` | 店舗情報に表示する定休日・駐車場の文 |

## ③ GitHubで公開する

1. GitHubで新しいリポジトリを作る（例：`grace-salon`、Public）
2. `index.html` と `README.md` をアップロード（Code.gs は載せなくてもOK）
3. Settings → Pages → Branch を `main` / `/ (root)` にして Save
4. 数分後 `https://<ユーザー名>.github.io/grace-salon/` で公開。このURLをLINEやQRコードでお客さんにシェア

## お店の毎日の使い方（スプレッドシートで）

| したいこと | やり方 |
|---|---|
| 予約を見る | 「予約」シートを開く（新しい予約はメールでも届きます） |
| 予約を取り消す | その行の「状態」を **キャンセル** にする → 枠がすぐ空きます |
| 電話予約・用事で時間をふさぐ | 新しい行に「予約日」「開始」「終了」を書く（例：`2026-11-03` `13:00` `15:00`、お名前に「電話予約 山田様」「休み」など） |
| 臨時休業（終日） | 新しい行に「予約日」だけ書き、開始・終了は空欄 |

※ お客様側の画面には時間の空き／埋まりだけが表示され、お名前などは外に出ません。
※ 予約の変更・キャンセルはお電話で受ける運用です。
